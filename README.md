# Aetherbook Themes

Aetherbook Themes is a browser extension that restyles Facebook's website for the person using it. It does not change Facebook account data, posts, messages, or what other people see.

## Install in Chrome or Microsoft Edge

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome, or `edge://extensions` in Edge.
3. Turn on **Developer mode**.
4. Choose **Load unpacked** and select this project folder.
5. Open or refresh `https://www.facebook.com` and choose the extension to select a theme and configure the wallpaper.

The extension includes Classic, Twitter-inspired, Futuristic (neon colors), Midnight (dark mode), Lavender, and Forest themes, plus custom page, card, text, and accent colors. Themes change colors only and preserve Facebook's layout and spacing. Futuristic uses a dark navy palette with cyan accents; Midnight applies dark colors. Theme changes apply immediately and automatically style newly loaded Facebook content. The optional nebula wallpaper remains available separately and respects the browser's reduced-motion preference. Settings are stored in browser sync storage.

Facebook's page structure can change, so some parts of the site may not pick up a theme consistently. The extension only runs on `facebook.com` and `www.facebook.com`.
